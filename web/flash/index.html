The Snoop37 screen, on a big screen

snoopview shows the Snoop37 keyboard's 240×240 screen at exact 2× on a 7" ESP32-P4 panel, with a piano, the pads, a cheat sheet and song pages on the sides. Install it from this page: no tools to set up.

Install

 

This browser cannot talk to a USB serial port. Use Chrome or Edge on a computer (Windows, macOS or Linux). The installer needs a secure page. Open this page over https.

This replaces the firmware on the board. snoopview saves nothing on the board, so there is nothing to lose from an older snoopview.

What you need

  • A Guition JC1060P470C board (ESP32-P4, 7" 1024×600 panel). The firmware is for this board only.
  • A USB-C data cable.
  • Chrome or Edge on a computer.

Steps

  1. Connect the computer to the board's "Full Speed USB" port.
  2. Click Connect and install.
  3. Select the port named USB JTAG/serial debug unit, then click Connect.
  4. Click Install snoopview. Wait until it says the installation is complete (about one minute).
  5. The board restarts. You see a test pattern and waiting for snoop37.
  6. Connect the keyboard to the board's "High speed USB" port. The keyboard's screen comes on the panel.

If the port does not show, or the installation does not start: hold the board's BOOT button, press RESET, release BOOT, then try again. Press RESET after the installation.

The keyboard's firmware

The keyboard (M-Vave SMK-37 Pro) must run Snoop37 with the screen mirror. Other firmwares do not send the screen: the panel stays on the test pattern. Install it one time, from the fork's page:

  1. Connect the keyboard to the computer with a USB data cable. Close other apps that use MIDI.
  2. Open themonkeyz.github.io/sloop-fm1 in Chrome or Edge.
  3. Click Open the installer, then Install. Let the browser use the MIDI devices.
  4. Do not unplug the cable while it writes. The keyboard restarts when it is done.
  5. Connect the keyboard to the board's "High speed USB" port.

Projects, presets, samples and settings stay on the keyboard. It is an experimental firmware, not from M-Vave: you install it at your own risk. That page also says how to go back.
